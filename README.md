# NOME_DO_JOGO

Jogo ORIGINAL de navegador, no gênero de criaturas colecionáveis feitas de partes: batalha 3 contra 3 com cartas, cruzamento, mercado entre jogadores e economia de token com modelo econômico sustentável. Nome, criaturas, arte e cartas são próprios; nada é copiado de jogo existente.

- Pilha: Node 22 sem dependências, SQLite embutido, tela em canvas. O servidor decide, a tela só mostra.
- Rede e token: a decidir pelo dono. Hospedagem e domínio: a decidir.
- Estado: estúdio montado (regras, equipe, skills, travas); o jogo ainda não começou. Nada está publicado.

## Por onde começar
- `PASSAGEM.md` — onde paramos e o próximo passo.
- `CLAUDE.md` — regras do projeto.
- `docs/decisions.md` — decisões do dono (a mais nova em cima).
- `.claude/EQUIPE.md` — a equipe de agentes; `docs/orquestra.md` — como se trabalha.

## Testes
- `npm test` — bateria do servidor (vazia por enquanto).
- `npm run test:travas` — travas do estúdio.
